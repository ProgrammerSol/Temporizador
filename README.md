# ⏳ Temporizador - Coming Soon

¡Un proyecto web interactivo de cuenta regresiva con diseño moderno, animaciones dinámicas y efectos visuales festivos! Este temporizador fue desarrollado como parte de mis prácticas de programación web.

🔗 **Enlace del proyecto en vivo:** [https://programmersol.github.io/Temporizador/](https://programmersol.github.io/Temporizador/)

---

## ✨ Características

- **Diseño Moderno:** Estilo inspirado en tarjetas de conteo con un fondo degradado en tonos púrpuras y efectos visuales de profundidad.
- **Temporizador Dinámico:** Cuenta regresiva interactiva controlada con JavaScript mediante intervalos de tiempo (`setInterval`).
- **Animación de Estrellas:** Al finalizar la cuenta regresiva (`0`), se dispara automáticamente una animación flotante de estrellas brillantes por toda la pantalla.
- **Diseño Responsivo:** Adaptado para verse genial en diferentes dispositivos.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5** (Estructura semántica del contenido).
- **CSS3** (Estilos avanzados, Flexbox, gradientes radiales/lineales y animaciones `@keyframes`).
- **JavaScript (Vanilla)** (Lógica del temporizador, manipulación del DOM y generación dinámica de elementos).
- **Google Fonts** (Tipografía *Montserrat*).
